Project X v1.3.2 Release Notes

Key Improvements & Fixes in this Release:

• Exact Digit Custom Duration Controls: Replaced confusing slider steps with high-precision -5m, -1m, +1m, and +5m nudge buttons across all custom duration dialogs (Study Timer, Default Starting Preset, and Daily Progress Limit). Select any exact minute effortlessly.

• Removed Misleading Slider Marks: Removed the off-center 45m mark from the 5m–120m sliders, providing clean and unambiguous range boundaries.

• Refined Extended Session Advice Threshold: The knowledge retention pacing reminder now activates strictly for extended study blocks longer than 45 minutes (46m+), keeping standard 45m sessions clean and uninterrupted.

• Butter-Smooth Rule Badge Transitions: Over-time advice and the 20-20-20 health rule badges now enter and exit with smooth vertical expansion and shrinkage easing, ensuring the timer card glides smoothly without jumping.

• Expandable Study Session Details: In the Study Sessions history, each card displays a clean initial label ("Completed at [time] • [duration]m"). Tapping the card smoothly reveals the exact study window ("from [startTime] to [endTime]").

• Started & Stopped Midway Counters: Daily session analytics now show both the total sessions started and sessions stopped midway (abandoned) alongside completed sessions for full focus accountability.

• Aligned Daily Progress Limit UI in Settings: Daily Progress Limit presets now match the visual layout, uniform chip dimensions, and horizontal scrolling of the Default Starting Preset row.

• Clean In-App Update Notes Formatting: Update changelogs are parsed and formatted with native typography, eliminating raw markdown symbols and hashtags.

• Persistent Crash Diagnostics: Offline crash reporting screen remains active in an isolated process for debugging support.
