Project X v1.3.3 Release Notes

Key Improvements & New Features in this Release:

• Replaced Streak Card Fire Emoji with Native Icon: Replaced the textual flame emoji in the daily streak status with a dedicated Material theme flame icon for a clean, consistent design.

• 5 Beautiful Default Color Palettes + Dynamic Wallpaper: Expanded appearance customization beyond purple. You can now choose from 5 vibrant Material 3 color themes (Classic Violet, Ocean Blue, Emerald Green, Sunset Orange, and Rose Pink) or select Dynamic Material You to extract colors from your device wallpaper.

• Selectable Timer Animations: Introduced 4 distinct progress ring animations for the strict focus timer without removing the default:
  1. Classic Circle: The original clean circular progress ring.
  2. Wiggly Wave: A dynamic undulating sine-wave progress that ripples in real-time as the timer runs.
  3. Material Segmented: 60 radial chronograph tick marks with pulsing active highlights.
  4. Pulsing Halo: Concentric breathing neon glow that pulses gently while you focus.

• Symmetrical & Aligned Appearance Settings: Accent palette swatches and timer animation options are aligned with smooth horizontal scrolling and clear selection indicators.

• Persistent Crash Screen: Offline crash diagnostics remain active in an isolated process.
