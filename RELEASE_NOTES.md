Studyio v1.4.6 Release Notes

Key Improvements & Fixes in this Release:

• Restored Classic v1.4.1 Wiggly Progress Dial: Restored the exact, clean sinusoidal oscillating wave progress bar from v1.4.1. It features no background circle, natural 14-cycle wave frequency, smooth sinusoidal undulation, and clean 10.dp stroke.

• Idle & Active States: In idle state (before timer starts), a subtle low-opacity full 360° wavy ring is displayed. When active, the dynamic wave line fills clockwise along the timer's elapsed arc with smooth wavePhase motion.

• Everything Else Untouched: All other features, including Google Sans Flex variable typography, Nordic Teal and brand themes, AMOLED pitch-black mode, custom presets persistence, offline crash diagnostics, and remaining timer dials remain completely intact.
